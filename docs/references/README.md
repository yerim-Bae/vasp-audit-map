### 감독지침 Ⅲ-4 (p21~24) 요지 — 원문 확인

- **쟁점**: 사업자가 고객위탁 토큰을 자산·부채로 인식하는가. 고객위탁 토큰 범위는 매매 예탁뿐 아니라 스테이킹 등 서비스 이용을 위한 예치도 포함 (p21).
- **판단 기준**: 고객과 사업자 중 누가 토큰을 **통제**(경제적 자원의 사용을 지시하고 효익을 얻는 현재의 능력)하는지. 세 지표를 종합 고려하며 하나가 결정적이지 않다 (p21).
  1. 사업자·고객 간 사적 계약 — 소유권 이전 여부, 고객 동의 없이 판매·이전·대출·담보 가능 여부, 고객의 언제든 인출 가능 여부, 하드포크 시 수혜자 등 (p22)
  2. 감독 법령 — 가상자산법의 이용자 명부(§7①), 분리보관·현실적 보유(§7②), 입출금 이용자 결정(§11), 보험·준비금(§8); 파산 시 고객 권리 존재 여부 (p21~22)
  3. 관리·보관 수준 — 개인키 분실 시 손실 부담자, 분리보관 여부, 주소 추적 가능성, 제3자 수탁 여부, 핫/콜드월렛과 보호장치 (p23)
- **사업자 자산·부채로 계상하는 경우**: 평가손익은 상쇄 계상, 자사거래소 가격 적용, 주석 공시 (p22).
- **인식하지 않는 경우의 주석 공시(예시)** (p23): 고객위탁 토큰 종류·수량·기말 공정가치, 고객 소유로 판단한 근거, 서비스별 권리·의무, 청산 시 고객 청구권, 해킹 보호 절차, 외부 위탁 현황, 거래원장 검증절차, 전자지갑 보관정책.
- **사업자 보유 토큰** (p24): 규제 등으로 매도·중개 못 하고 보유 → 무형자산(원가모형 또는 재평가모형). 중개기업이 일반상품인 가상자산을 단기 매도 목적으로 취득 → 재고자산(일반기업회계기준은 기타자산 가능), 순공정가치 측정·당기손익. 영업에 사용 → 재고자산 저가법.

이 요지는 데이터 레코드의 `rationale` 에서 "감독지침 Ⅲ-4-가 (p21~23)" 형식으로 인용한다.
