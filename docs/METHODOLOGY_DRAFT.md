## 1. 이 데이터셋은 무엇인가

국내 금융정보분석원(FIU) 신고 가상자산사업자(VASP) [45]곳의 신고 현황, DART 법인 정보, 감사보고서, 재무제표 핵심 수치,
가상자산 관련 회계정책·주석, 그리고 그로부터 도출한 잠재 감사위험을 하나의 구조로 연결한 공개 데이터셋이다.

세 가지 용도를 위해 만들었다. (1) VASP 감사에 처음 투입되는 회계사가 회사의 사업모델과 계정, 재무제표 주장, 감사위험을 30분 안에 파악하는 것,
(2) 가상자산 회계처리가 회사마다 실제로 어떻게 다른지 원문으로 비교하는 것, (3) 출처와 확인일, 사실과 추론의 구분이 눈에 보이는 방법론을 남기는 것.
투자 판단용이 아니다.

## 3. 출처 우선순위

1. FIU 공식 명단 (신고 상태·법인명·사업자등록번호·신고 업무) — 명단의 유일한 근거. 언론·과거 자료로 현재 상태를 판단하지 않았다.
2. DART 공시 (법인 식별, 감사보고서, 재무제표, 주석) — 감사의견·감사인·계속기업 문구는 감사보고서 **원문**에서 확인했고, 검색 제목이나 API 요약값만으로 기록한 값은 없다.
3. 회사 공식 웹사이트 (실제 서비스, 원화마켓 여부, 수수료, 보관 방식) — DART 로 확인할 수 없는 서비스 정보에만 사용.
4. 그 외 (언론·리서치) — 보조자료. `source_authority: OTHER`, `confidence: inferred` 이하로만 기록.

## 4. 법인 매칭 규칙

FIU 명단의 법인명으로 DART 법인 후보를 찾은 뒤, DART 기업개황의 **사업자등록번호가 FIU 사업자등록번호와 일치할 때만 exact** 로 연결했다.
이름만 비슷한 경우는 연결하지 않고 `needs_review` 로 남겼다. DART 에 없는 법인은 `not_found` 이며, 이는 "외부감사 대상이 아닐 가능성" 을 뜻할 뿐 확정이 아니다.
매칭 실패·모호 건은 모두 `needs-review.json` 에 있다 ([ ]건).

## 5. 사실과 추론의 구분

| 표시 | 뜻 | 어디에 |
|---|---|---|
| `fact` / `source_based` / `verified` | 원문(FIU·DART·회사 공식자료)에서 직접 확인 | 역할·수익모델·감사위험·주석 |
| `inference` / `analytical_inference` / `inferred` | 확인된 사실에서 분석자가 도출. 근거 레코드를 `evidence_source` 에 명시 | 감사위험, 요약 |
| `unverified` / `null` / `needs_review` | 확인 못 함. 0 이나 추정값으로 채우지 않음 | 전 파일 |

없는 계정은 `0` 이 아니라 `null` 이다. `0` 은 원문에 0 으로 표시된 경우에만 쓰고 `notes` 에 근거를 적었다.

## 6. 단위와 범위

- 금액은 모두 **원(KRW) 단위 정수**. 원문이 천원 단위이면 환산하고 `original_unit` 에 남겼다.
- 연결(consolidated)과 별도(separate)는 별도 레코드다. 한 레코드에 섞지 않았다.
- 주석 인용(`evidence_excerpt`)은 300자 이내로 제한하고 나머지는 요약했다. 감사보고서 전문은 저장하지 않았다.
- 감독지침상 사업자의 고객위탁 가상자산 관련 사항은 2024.7.19 이후 재무보고일부터 적용되므로, FY2023 과 FY2024 이후의 표시 방법이 다를 수 있다. 연도 간 비교 시 이 단절을 `notes` 에 적었다.

## 7. 품질검사

`scripts/validate.py` 가 다음을 자동 검사하고, 최종 실행 결과는 [0 errors, N warnings] 이다.
중복 법인 · 서비스명과 법인명 뒤바뀜 · 연결·별도 혼합(자산 = 부채 + 자본 대조) · null→0 변환 · 출처 없는 사실 · 원문 미확인 감사의견 · 연도 범위 · 파일 간 참조 무결성.
